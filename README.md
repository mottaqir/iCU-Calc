# 🩺 iCU Calc

> **Your Compact Bedside Clinical Companion**

iCU Calc is an offline-capable Progressive Web App (PWA) designed to help critical care and emergency physicians access essential clinical information quickly and reduce cognitive load at the bedside.

**⚡ Quick Access · 📱 Offline-Capable · 🧠 Clinically Focused**

[**🚀 Try the Live Demo Here**](https://mottaqir.github.io/iCU-Calc/)

---

## ✨ Features

*   **💉 Bolus Drugs:** Emergency and push medication dosing, including weight-based calculations.
*   **💧 Infusion Drugs:** Infusion-rate calculations for vasopressors, sedatives, cardiac drugs, and other critical medications.
*   **🧮 Special Calc:** 
    *   📋 Assessments, Scores & Clinical Criteria
    *   🧪 Calculators & Corrections
    *   🩸 ABG Analysis
    *   ⚖️ Unit Converter
    *   ⚡ At a Glance
*   **🦠 Antibiotic Coverage**
*   **🦟 Dengue Guideline 2025**
*   **❤️‍🩹 Cardio / Defib:** Quick-reference resources for ECG emergencies, antihypertensive drug use cases, cardiac arrest, and arrhythmia protocols.

## ⚙️ Smart Features

*   🔎 **Global Search** — Find information and jump directly to the relevant card.
*   ⚖️ **Global Weight Slider** — Adjust patient weight for dynamic weight-based calculations across tabs.
*   🔀 **Quick Tab Switch** — Switch between main tabs without scrolling back to the top.
*   🔗 **Reference Web Links** — Access relevant external references and source materials.
*   🌓 **Dark / Light Theme** — Choose your preferred appearance.
*   🗂️ **Structured Navigation** — Categories, cards, sub-cards, and clinical notes for quick bedside reference.
